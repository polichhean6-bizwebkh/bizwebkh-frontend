# C021 ROCKRETE Cambodia

Static one-page business website for **ROCKRETE (CAMBODIA) CO., LTD**.

Demo URL: https://www.bizwebkh.com/c021-rockrete/

## Services

- Surface Preparation
- Floor Finishing
- Stone Polishing
- Waterproofing Systems

## Technology

HTML, CSS and vanilla JavaScript. No build process, database, backend, payment, booking system, or customer login is included.

## Deployment

1. Upload the contents of this folder to the `c021-rockrete` directory on the web host or to a GitHub Pages deployment configured for that subdirectory.
2. Keep `index.html` at the deployed folder root.
3. Preserve the lowercase filename casing and relative asset paths.
4. Confirm the live demo opens at `https://www.bizwebkh.com/c021-rockrete/`.

All site paths are relative so the demo works when hosted inside the `/c021-rockrete/` subdirectory.
