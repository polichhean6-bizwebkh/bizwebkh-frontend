## Local preview

Open `index.html` in a modern browser, or serve this directory using any static web server.

## Deployment

Upload the contents of this `c020-little-learners` directory to the intended hosting subdirectory. All website paths are relative, so the site works at `/c020-little-learners/` without requiring domain-root hosting.

## Folder structure

```text
index.html
404.html
css/       Website styles and motion layer
js/        Navigation, interaction, and animation scripts
assets/    Logo and optimized client photography
```

- Branch addresses and Google Maps links must be confirmed before launch.
- The official Telegram link must be confirmed before one is published.
- Program schedules and included services may vary by age group and branch.
- Promotion content was intentionally excluded.
