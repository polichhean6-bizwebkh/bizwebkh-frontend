# Hearing Solution Cambodia Booking Dashboard Demo

This project is a static visual preview of an internal booking dashboard. It is not a production system.

## Start the demo

Open `login.html` in a browser. Any values can be entered to continue to the visual dashboard.

## Demo pages

- `login.html` — visual sign-in preview
- `index.html` — dashboard summary
- `bookings.html` — searchable and filterable sample booking list
- `booking-detail.html` — booking detail and visual status control
- `reports.html` — three-month fictional report and sample CSV export

## Safety and data notes

Authentication is not real, OTP is not included, and changes are not stored. All records, names, and masked phone numbers are fictional sample data. Reports and CSV export use only the bundled fictional data. The production Next.js booking system is maintained separately.
