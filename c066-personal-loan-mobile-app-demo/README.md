# C066 – Personal Loan Mobile App · UX/UI Demo
Client: Mr. Daily Daily · Prepared by BizWeb KH

## How to open
Double-click `index.html` (Chrome / Edge). Works offline – Khmer fonts are bundled in `fonts/`.
On desktop it shows a phone frame + a review panel (phone size, language, jump-to-screen).
On a real phone it fills the screen.

## Notes
- DEMO ONLY: no backend, no payment gateway, no banking, nothing deployed.
- All names, phones, villages and amounts are mock data. Dates are relative to today so reminders always look live.
- Changes you make while testing are kept in the browser only. Use More → About → "Reset demo data" to restore.
- Interest/schedule calculations are simulated and are not legal or accounting advice.
