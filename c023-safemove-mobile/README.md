# SafeMove Express Mobile App UX/UI Prototype

This folder contains the static, clickable SafeMove Express mobile app UX/UI prototype prepared for client review and GitHub Pages hosting.

## Open locally

Run a static server from this folder:

```text
python -m http.server 8000
```

Then open `http://localhost:8000/`.

No build command, package installation, backend service, database, or environment file is required.

## Main prototype flow

Sign in or register → Home → Express delivery → Item details → Order review → Order confirmation → Tracking.

The bottom navigation also opens Orders, Tracking, Alerts, and Profile. Laundry, Mart, Food, and Promotions are included as clickable concept screens.

## Prototype limitations

This is an interactive UX/UI concept for client review. Authentication, payments, uploads, live GPS tracking, notifications, messaging, production data, and external API integrations are simulated or intentionally excluded.

All names, phone numbers, routes, prices, order IDs, and promotion codes are fictional demonstration data.
