Child Development and Therapy Management System

01 / Overview

How the system works

The demo follows each child’s development journey. Staff open a child, review skills and goals, record sessions and observations, then use progress views and reports to share next steps.

1. Open a childFind an existing child profile.
2. Review skillsUse the Development Profile and plan.
3. Record supportAdd goals, sessions and observations.
4. Review progressCompare development and prepare a report.
Dashboard

Daily development overview

Purpose: Gives management and staff a quick picture of children, plans, today’s sessions, goals, reviews and recent progress.

Main functions:

  • View key counts and today’s session list.
  • Open progress, schedule, notes, goals and parent-review shortcuts.
  • See development overview and recent goal progress.

Typical use: Start the day by reviewing scheduled sessions and children who need a development review.

Children and Child Profile

Find the child’s full development workspace

Purpose: The Children page lists seeded demo children. The Child Profile brings their development information together.

  • Search by child name, ID or fictional phone reference.
  • Filter by program.
  • Open profile tabs: Overview, Development Profile, Goals, Sessions, Attendance, Progress, Documents and Parent Notes.

The current demo can view children but does not add or edit core child details.

Typical user action

Select Open profile from the Children list before reviewing skills, goals, sessions or progress for that child.

Who uses it: Director sees all seeded children; staff roles show seeded assigned-child scope; Parent View does not show this directory.

Development Profile

Track observable development skills

Choose a child, compare baseline with current review, open a domain and update individual skills using five stages: Not Started, Emerging, Developing, Achieved and Generalized.

Domains: Communication & Language, Social Interaction, Emotional / Behavior Regulation, Cognitive / Learning, Adaptive / Daily Living Skills, Fine Motor, Gross Motor / Physical Development, Sensory Processing, Attention / Participation and Independence / Self-Care.

Percentages summarize the saved fictional skill stages. They are not diagnosis or medical-severity scores.

Individual Development Plan

Set shared priorities and review dates

Main functions: View or edit the plan period, start/review dates, development priorities and review notes; add or manage goals below the plan.

Typical use: Record the priorities for a plan period, then add the goals the team will work toward.

The demo has one editable plan object per child and displays it as Active.

Progress Tracking

Compare baseline and current development

Main functions: Toggle between Baseline June and Current September, review every domain’s percentage-point change, view the fictional journey timeline and open the report.

Typical use: Review progress before a team or parent meeting.

Therapy Sessions

Record therapy and education work

Main functions: Add or edit a session with child, specialist, service, date/time, duration, status, goals, activities, response, assistance, notes, home recommendation, evidence label and next session. Filter Scheduled, Completed or Cancelled sessions.

Services: Special Education, Speech Therapy, Occupational Therapy, Psychology, Physical Therapy and NeuroTrack / Development Support.

Typical use: Complete a session note after a session, then select parent approval only when the note may be shared.

Assessments

Record a development review

Save an Initial Baseline, Quarterly Review or Annual Review with reviewer, domain, skill, current level, observation, support needed and recommendation.

Typical use: Record an observation at a planned review. The selected current level updates that skill’s current demo stage.

Goals and Interventions

Keep goals specific and visible

Add or edit a goal, select its domain and responsible staff, record baseline, target, activities, dates, percentage and stage. Update progress, mark achieved and view history.

Team Case Review

Coordinate next actions

Create a review with meeting date, participants, current progress, challenges, goal adjustments, parent feedback and next actions.

Typical use: Save an agreed summary after a multidisciplinary meeting.

Attendance

Mark a simple daily status

Choose Present, Absent, Late or Excused for each visible child and view an illustrative September summary.

The previous attendance totals are fictional. The demo is not a dated attendance ledger.

Schedule

Review the weekly timetable

Move to previous/next/current week, schedule a session, open session details and review color-coded service entries plus sample parent/team review events.

There is no recurring appointment or scheduling-conflict check.

Staff and Parent Communication

See the team and record contact

Staff: View fictional staff role, specialty, assigned-child count, sessions today and upcoming schedule. Staff records are read-only.

Parent Communication: Add a contact log with guardian, date, Phone/Telegram/In Person method, reason, notes, follow-up date and acknowledgement.

Communication methods are record labels only; the demo does not send messages.

Typical communication action

After a family conversation, select the child, add the reason and notes, set a follow-up date if needed, then save the log.

Progress Reports

Prepare a parent-friendly progress summary

Child Development Progress Report: child/team details, development summary, previous/current domains, achieved and in-progress goals, approved comments, home recommendations and next priorities.

Actions: Preview, Print and Export PDF guidance through the browser’s Print → Save as PDF option.

Operations reports: Development Progress by Child, Development Progress by Domain, Goals Status, Sessions by Service, Attendance, Children Due for Review and Therapist Workload.

Filters: child, program, specialist, domain, goal stage and date from, where relevant to the selected report. Operations reports offer View report, Export CSV and Print report.

Development Analytics

Review operational summaries

Shows average progress by domain, goals by stage, children by primary support area, sessions by service and children due for review.

This Director-only page uses fictional demo data and has no export control.

Users and Roles

Demonstrate each role view

The dropdown can switch among Director / Administrator, Special Education Teacher, Speech Therapist, Occupational Therapist, Psychologist, Physical Therapist and Parent.

Director: all modules and seeded children. Staff roles: assigned-child scope and their own service sessions; Staff, Users & Roles, Activity Log, Settings and Development Analytics are hidden. Parent: one child’s summary, goals, progress, sessions and reports with approved notes only.

This is a visual role simulation. It is not real login, account management or security.

Parent View

Share an approved family-facing view

View Development Summary, Goals, Progress, Sessions and Progress Reports. Approved team notes, home recommendations and upcoming sessions can be shown.

Typical use: Switch to Parent role during a presentation to demonstrate the family experience.

Parent View has no editing controls and hides unapproved note content.

Special Education Teacher

Classroom and development support

Main navigation: Dashboard, Children, Development Profiles, Individual Development Plans, Progress Tracking, Therapy Sessions, Assessments, Goals & Interventions, Team Case Review, Attendance, Schedule, Parent Communication, Progress Reports and Documents.

Typical workflow: Open a child, update a skill or goal, record a Special Education session, then review progress or add attendance.

The initial fictional data assigns this role to all 20 seeded children.

Therapist roles

Service-specific session views

Speech Therapist, Occupational Therapist, Psychologist and Physical Therapist share the same staff navigation. Their Sessions page is scoped to the role’s own service and visible assigned children.

Common workflow: Open an assigned child, review profile and goals, add a service session, update progress/observations, then prepare parent-approved recommendations when appropriate.

Important: The current demo does not enforce a domain-only editing rule for any therapist role.

Parent

Family-facing progress view

Main navigation: Overview, Goals, Progress, Sessions and Progress Reports.

Daily use: Review development summary, shared goals, current progress, upcoming sessions, approved notes and home recommendations.

Parent access is more than a communication function: it is a separate five-module screen experience. However, it is fixed to one fictional child and has no real authentication, messaging delivery or editing controls.

Other demo functions

Documents, Activity Log and Settings

Documents: Add and preview document title, type, date and text. No file upload or download exists.

Activity Log: Shows recent locally saved demo actions. It is not a secure multi-user audit trail.

Settings: Edit stage names/descriptions, reset local fictional data after confirmation and use the top-bar English/key Khmer label switch.

Demo boundaries

  • All children, guardians, staff, sessions and reports are fictional.
  • Changes save only in the current browser using localStorage when available.
  • No backend database, real login, payment service, external messaging, medical diagnosis or actual file upload is included.
  • Browser Print / Save as PDF is used for report PDF output.
  • English is primary; Khmer coverage is provided for key navigation and labels.
