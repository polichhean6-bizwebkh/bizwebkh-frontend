# C040 — Norea Square & Diamond Bay Garden Client Review Demo

Static client-review demo for Norea Square Condominium and Diamond Bay Garden in Phnom Penh.

## Included

- Project storytelling, residences, facilities, floor plans, galleries and brochures
- Public pricing and availability presentation
- Diamond Bay Garden payment terms
- YouTube project video
- Client-confirmed phone, email and Telegram contact links

## Notes

- This is a review demo only. It has no live booking, payment, availability database or form submission backend.
- Prices, availability, promotions and payment terms are subject to sales-team confirmation, as stated in the site.
- The demo includes a `noindex,nofollow` robots meta tag.

## Entry point

Open `index.html` locally, or host this folder as the `c040-norea-dbg-github-review-final` subfolder of the `bizwebkh-frontend` repository for GitHub Pages review.

All CSS, JavaScript, images and brochure-download paths are relative and compatible with subfolder hosting.
