# C044 Education Content Demo

Static one-page promotional website for an educational content seller.

Open `index.html` in a browser to preview.

## Replace before launch

- `USERNAME` in `index.html` and `js/main.js` with the real Telegram username.
- Phone and Facebook placeholders in the contact section.
- Demo product names, prices, and descriptions as needed.

This is intentionally a front-end-only $99 package demo: no cart, payments, login, database, backend, or CMS.
