# S Rungreung Website Demo

Static client presentation website for S Rungreung.

## Included

- Khmer-first website with an English language switch
- Vehicle-document consultation service pages
- Demo-only inquiry forms and direct-contact links
- Optimized WebP photography and favicon assets

## Publish with GitHub Pages

Upload the contents of this folder to a repository, then enable GitHub Pages from the repository root on the selected branch. The site entry point is `index.html`.

This is a static demo. Inquiry forms are not connected to a production backend.
